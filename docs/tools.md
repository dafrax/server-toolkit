# Tool Reference

## Storage

### fio
Storage benchmark and workload generator.

### iostat
CPU and block-device statistics. Provided by `sysstat`.

### iotop
Shows which processes are performing disk I/O.

### lsof
Finds processes holding files, sockets, mount points, and devices.

## Network

### mtr
Combines ping-style latency/loss measurements with route visibility.

### tcptraceroute
Performs traceroute using TCP. Useful when ICMP/UDP traceroute is filtered and for checking an application port such as TCP/443.

### tcpdump
Packet capture and low-level network troubleshooting.

### iftop
Real-time bandwidth usage by connection.

### iptraf-ng
Interactive traffic/interface statistics.

### nc / ncat
Quick TCP/UDP connectivity and listener tests.

### dig
DNS query and troubleshooting utility.

## Debugging

### strace
Observes system calls and signals made by a process.

### lsof
Useful for identifying which process owns a port or file.

## Monitoring

### htop / btop
Interactive process and resource monitoring.

### atop
Historical/current system resource and process monitoring when configured appropriately.
